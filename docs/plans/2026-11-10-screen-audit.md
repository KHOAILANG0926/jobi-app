## 제안
1. 화면 대조 검사: 새 공고가 공개 후보가 되면 기존 "상세 화면 읽기"(scripts/ops/detail-read.mjs, 운영 화면 PC·모바일 글)를 돌려 화면 글·링크를 원문(source_text)·DB와 대조
   - 상단: 제목이 기호로 시작/잘림, 회사 줄이 회사명 중간부터, 급여 = 원문 금액 그대로
   - 지도: Google 버튼 목적지 = 지도 핀 좌표(핀 출처 Google일 때), 핀 좌표 = /api/map-locations 값
   - 연락처: 화면 전화·Zalo가 원문에 있는 번호
   - 아이콘·Phúc lợi: 켜진 항목마다 원문(또는 포스터 글자) 근거 줄이 있는지
   - 원문에 없는 글이 화면에 있음 / 원문 핵심 줄이 화면에 없음
   - 실패면 공개하지 않음(기존 검사표 hold 경로 그대로)
2. 지금 공개 중인 공고 전체를 1로 한 번 점검(크롤링 확대 전)
3. 점검 끝날 때까지 크롤링은 1건씩
