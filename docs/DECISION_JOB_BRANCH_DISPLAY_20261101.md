# 결정 요청 — 다지점 회사명과 지점명 표시 (2026-11-01)

## 확정된 내용
- 공고 상단은 승인된 기존 틀을 유지한다. 새 배지·행·칸을 임의로 만들지 않는다.
- 회사명, 지점, 근무지 주소는 서로 다른 개념으로 추출·보존한다.
- 원문 또는 OCR에 없는 지점명을 주소로 추정하지 않는다.
- 회사명이나 지점명에 관한 수정은 공고 번호 전용 분기가 아니라 공통 규칙으로 적용한다.
- 위치 원본 job_work_locations 및 확정 좌표는 이번 결정 대상에서 제외한다.

## Lee 결정 필요 (운영 변경 전)
1. 제목에 회사명이 이미 등장할 때 회사명 표시 줄의 중복을 없애고, 지점명이 명시된 경우 **두 번째 줄에는 지점명만** 표시하는 방식으로 확정할까요?
2. 지점명이 없으면 두 번째 줄 **전체를 표시하지 않고** 공간도 차지하지 않는 방식으로 확정할까요?
3. 여러 지점이 동일 공고에 등장하면 기존 근무지 영역에서 **원문 순서대로 각각 표시**하고 상단에는 별도 지점명을 선택하지 않는 방식으로 확정할까요?

## 결정 후에만 구현할 범위
공통 추출기 → 정규화된 회사/지점 필드 → 기존 카드·상세 표시 → 원문 대조 검사 → CI 회귀 테스트.
원본 문자열은 손실 없이 보존한다. 샘플 #5157은 회귀 검증에만 사용하며 전용 예외를 추가하지 않는다.
