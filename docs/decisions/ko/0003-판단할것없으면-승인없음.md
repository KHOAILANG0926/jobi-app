# 결정 0003 — Lee가 판단할 것이 없으면 Lee 승인도 없다

- 상태: **제안** (Lee 승인 시 "확정")
- 날짜: 2026-10-18
- 누가 정함: Lee (2026-10-18 대화: "도장 찍기만 할 거면 내 승인이 왜 필요하냐", "규칙도 생명이지만 속도도 생명")
- 영어판: `docs/decisions/en/0003-no-judgment-no-approval.md`

## 결정
1. Lee 승인은 **Lee가 내용을 읽고 판단할 수 있는 것**에만 둔다. 지금은 **결정 문서(이 폴더)뿐**이다 — "AI가 Lee 말을 맞게 받아 적었나" 확인.
2. 기술 파일(검사 설정, 코드, DB 변경, 범위표)은 Lee 승인 없이 **기계 검사**로 지킨다.
3. 범위표 2단계(범위 PR → 구현 PR)는 폐지한다. PR은 작업당 1개.
4. AI는 대화에서도 Lee가 판단할 수 없는 기술 단계를 "승인해 달라"고 하지 않는다.

## 지키는 장치
- GitHub가 Lee 승인을 요구하는 파일 목록(CODEOWNERS)은 결정 문서와 그 목록 자체만 허용. 다른 항목이 추가되면 필수 검사 `checks`가 빨간불 (`scripts/check-approval-scope.mjs`).
- 그 목록을 바꾸는 것도 Lee 승인 필요 → AI 혼자 승인 대상을 늘릴 수 없음.
- 4번(대화)은 기계로 못 막음: 장치 없음.
