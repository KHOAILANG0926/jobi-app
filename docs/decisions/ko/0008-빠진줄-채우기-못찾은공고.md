# 결정 0008 — 빠진 줄은 막지 않고 채운다 / 못 찾은 공고는 삭제하지 않고 저녁에 보고

- 상태: **제안** (Lee 확인 시 "확정")
- 날짜: 2026-10-20
- 누가 정함: Lee (2026-10-20 대화)
- 영어판: `docs/decisions/en/0008-fill-missing-lines-unlocated-jobs.md`

## 1. 상세요강 빠진 줄
- Lee: "공개를 막는 게 아니라 어떻게서든 구현을 해서 수정할 생각을 해"
- 원문(게시글·포스터)에 있는데 공고 글에 빠진 줄은 **공개를 막지 않고** 원문 글자 그대로 맞는 칸에 자동으로 넣는다.
- 지금 규칙에 없는 종류의 줄은 일단 기타란(07)에 넣고, 매일 아침 8시 52분 알림으로 Lee와 칸을 정해 새 규정으로 추가한다. 규정이 바뀌면 전체 공고를 자동으로 다시 나눈다.
- Lee: "저런 거는 그냥 기타란으로 넣어야지 넣을 데가 없잖아" → 두루뭉술한 문구(장점 문구, 끝맺음 권유, "TUYỂN FULL")는 묻지 않고 기타란.

## 2. 위치 못 찾은 공고
- Lee: "1번은 오케이"(원문에 위치 정보 없음 → 삭제), "고쳐서 못 찾으면 해결책을 찾아야지… 따로 리스트를 만들어서 저녁에… 알람 형식으로"
- 위치를 찾음(확인 좌표·공단 입구·동 중심·공단 이름) → 공개 유지.
- 원문에 위치 정보가 아예 없음 → 바로 삭제(지원·메시지·면접 기록이 있으면 비공개로 두고 목록에 올림).
- 원문엔 주소가 있는데 우리가 못 찾음 → 비공개, **자동 삭제하지 않는다.** 매일 저녁 8시 목록(주소·이유·해결 방법)을 Lee에게 보내고, 매일 새벽 3시 고친 코드로 다시 찾는다.
- 이전 계획(14일 뒤 자동 삭제, 결정 0006 초안)은 쓰지 않는다.

- 알림: 예약 점검 2개(아침 8시 52분 새 종류 줄, 저녁 8시 못 찾은 공고).
