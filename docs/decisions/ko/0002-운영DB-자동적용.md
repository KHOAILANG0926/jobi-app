# 결정 0002 — 운영 DB 변경은 자동 적용

- 상태: **제안** (Lee 승인 시 "확정")
- 날짜: 2026-10-18
- 누가 정함: Lee (2026-10-18 대화: "자동 적용하자. 할 일이 많아 일일이 할 수 없다")
- 영어판: `docs/decisions/en/0002-db-auto-apply.md`
- 0001의 "아직 정할 것"을 정함

## 결정
검사를 통과해 master에 병합된 운영 DB 변경(migration)은 **AI가 Lee에게 묻지 않고 자동 적용**한다.

## 지키는 장치
- 적용은 GitHub 자동 작업 `migrations-apply.yml`만 한다 (AI 계정은 운영 DB에 직접 쓸 수 없음 — DB 연결은 읽기 전용).
- 병합 전 필수 검사 통과가 조건. 파일마다 한 묶음으로 적용, 실패하면 그 파일 전부 취소·빨간불.
- 적용 후 운영 점검 SQL 자동 실행.

## 예외 (여전히 Lee 판단)
- 데이터 **삭제**, 공개 기준 변경, 되돌리기 어려운 변경 → 0001에 따라 Lee가 정함.
