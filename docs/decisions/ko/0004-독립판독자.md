# 결정 0004 — 포스터 확인은 능력이 검증된 독립 판독자로

- 상태: **제안** (Lee 승인 시 "확정")
- 날짜: 2026-10-18
- 누가 정함: Lee (2026-10-18 대화: "OCR이 제대로 못 하면 OCR 자체가 필요하냐", "진행하자")
- 영어판: `docs/decisions/en/0004-independent-reader.md`

## 배경
기존 OCR(Tesseract, 10-13 도입)은 실제 포스터 시험 없이 판정에 쓰였고, 칸 나뉜 디자인·흰 글씨를 못 읽어 정상 공고(#4828)를 막았다.

## 결정
1. Tesseract를 판정에서 뺀다.
2. 대신 **두 번째 AI가 입력값을 보지 않고 포스터만 보고 따로 읽는다**(이중 입력 검증). 입력값과 일치하면 통과, 다르면 보류.
3. 판독자는 **정답을 아는 실제 포스터 시험을 통과해야만** 판정에 쓴다. 판독자가 놓친 포스터가 생기면 시험에 추가한다.
4. 앞으로 새 검사 도구도 같은 기준: 실제 사례 시험 통과 전에는 판정에 쓰지 않는다.

## 지키는 장치
- 판독 작업은 매번 먼저 교정 시험(`scripts/ocr/ai-reader.test.mjs`)을 돌리고, 실패하면 판정하지 않음.
- PR 검사에서도 같은 교정 시험 실행.
- 판독자에게 입력값을 보내지 않음(코드로 고정).
