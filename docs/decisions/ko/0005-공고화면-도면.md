## 배경
5개월 동안 공고 화면 틀이 작업자(AI 포함)마다 조금씩 바뀌었다. 틀을 숫자로 정한 기준이 없었고, 화면 사진을 보고 판단했다.

## 결정
1. **도면**: 공고 상세 화면의 영역 순서·위치·폭·높이·간격·글자 크기·색을 숫자로 적은 파일 `docs/decisions/drawings/job-detail-layout.json`이 기준이다. 기준 공고는 CTY KDA(#4824), PC·모바일 따로.
2. **검사는 치수 측정**: 기계가 화면 각 영역을 숫자로 재서 도면과 대조한다(허용 ±1px). 사진 비교는 쓰지 않는다.
3. **대상**: 기준 공고 + 공개된 모든 공고, 이미지 있음·이미지 실패 상태, PC·모바일.
4. **빈값**: 값이 없어도 영역 자리를 유지한다. 가짜 값은 넣지 않는다.
5. **도면 변경은 Lee만**: 도면·측정기·그 검사를 부르는 필수 검사 파일은 Lee 승인 없이 바꿀 수 없다. 누가 작업하든(Claude·GPT·Gemini·현지 개발자) 같다.
6. **사고 → 시험**: 도면 위반 사례는 측정기 자가시험에 추가한다.
