# 0005 — 공단 공장 업무 미기재와 중개 공고 (Lee, 2026-10-27)

## 확정 결정
- 중개 공고를 받으며 실제 근무 회사명을 유지하고 `Tuyển qua nhà thầu`를 표시한다. 구직자 비용 요구 원문은 비공개·관리자 검토로 보낸다. 수수료 부정 문구나 `Hỗ trợ hồ sơ`를 비용 요구로 오인하지 않는다.
- 입사 보너스는 급여 총액에 더하지 않고 급여수당 칸에 별도 줄로 보존한다. 지급 조건을 만들지 않는다.
- 공단의 공장 공고이고 실제 업무가 미기재이면 가장 상위의 근거 있는 공식 코드까지 분류한다. 공단 밖 또는 공장 여부 불명은 기존 보류. 공단명만으로 공장이라 단정하지 않는다.
- 업무 칸에 `Công việc cụ thể: chưa ghi trong tin gốc` 표시. 원문은 수정하지 않는다.
- KTX와 숙소 지원은 복리후생 번호표로 표시. 방 찾기 지원을 현금 주거수당으로 바꾸지 않는다.
- 위치는 회사+공단 확정 기억을 우선 재사용하며 없으면 공단 입구와 정확도를 표시한다. 운영 DB 직접 접근 없이 기존 단일 writer와 migration/운영 검사 경로를 이용한다.
