# 승인된 공고 틀 변경 차단 (2026-10-16)

사용자 지시: 승인된 틀을 임의 변경하지 못하도록 자동 검사로 강제한다.

## 강제 장치
- `scripts/approved-layout-lock.json`: 기존 CTY KDA를 렌더링하는 카드·상세·관련 CSS 6개와 보호 workflow 2개의 SHA256 고정.
- `scripts/check-approved-layout.mjs`: 수정·삭제를 실패 처리. 기준표와 검사기 변경도 trusted 모드에서 실패.
- 기존 필수 `checks`에 검사 연결. `pull_request_target` 보호 workflow는 PR 코드가 아닌 기준 브랜치의 검사기·기준표를 실행한다. PR이 검사 단계나 보호 workflow를 삭제해도 기준 브랜치에서 차단한다.
- 보호 workflow는 read-only이며 secret·PR 코드 실행·checkout 인증정보 보존 없음.
- 관리자 설정 접근은 현재 브라우저 비로그인으로 불가. 기존 필수 checks는 PR #107 병합 시도에서 검사 진행 중 HTTP405로 병합 차단 확인. 신규 장치는 병합 후 위반 PR의 실제 실패·병합 거부로 추가 검증한다.

## 범위와 한계
- 소스 변경을 엄격히 동결한다. 픽셀 이미지 비교를 구현했다고 보고하지 않는다.
- 이번 작업은 기존 이미지 유무에 따른 좌측 공고 차이를 수정하지 않는다. 기존 결함이 없는 것으로 승인한 것이 아니다.
- 등록 데이터의 내용은 바꿀 수 있으나 보호 대상 화면 소스는 자동 변경할 수 없다.
- 합법적인 틀 변경에도 사용자 명시 지시와 별도 기준 갱신 절차가 필요하다. AI가 PR의 기준표를 스스로 고쳐 통과시킬 수 없다.
- 저장소 관리자 권한으로 보호 설정 자체를 해제하는 행위까지 막는 절대적 보안을 주장하지 않는다.

## 검증
- 기존 소스 통과, 수정/삭제 실패, 기준표 변조/검사기 교체 실패를 임시 테스트 파일로 확인.
- 앱 코드 변경 없음. 타입 검사·빌드·전체 테스트 및 원격 CI 결과는 PR 기록에 보존.
