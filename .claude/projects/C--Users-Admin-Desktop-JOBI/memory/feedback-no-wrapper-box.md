광고나 콘텐츠 블록을 배치할 때 불필요한 래퍼(하얀 박스, 여백 있는 컨테이너)로 감싸지 않는다.
콘텐츠가 할당된 영역을 꽉 채우도록 한다.

**Why:** 사용자가 광고판이 하얀색 박스 안에 들어가 있는 걸 보고 불필요하다고 지적. 공간 낭비이고 디자인이 안 깔끔해 보임.

**How to apply:** 광고 슬롯, 배너, 프로모션 카드 등을 배치할 때 래퍼 없이 직접 영역에 맞추기. border-radius는 콘텐츠 자체에 적용.
